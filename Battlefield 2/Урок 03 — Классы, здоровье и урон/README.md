# Урок 03 — Классы, здоровье и урон

[К списку уроков](../README.md) · [Предыдущий урок](<../Урок 02 — Dot и поле зрения/README.md>)

Превращаем игровой объект в класс со своим состоянием. Мишень хранит закрытое
здоровье и разрешает менять его через `takeDamage()`. Стенд читает состояние
через `getHealth()` и `isAlive()` и показывает его в сцене и на панели.

## Запуск

Откройте `VectorLab.exe` или `run.cmd` из этой папки. Сначала у мишени 100 здоровья,
она находится в секторе обзора. По умолчанию выбран урон 35.

| Управление | Действие |
| --- | --- |
| J / «Выстрел» / щелчок левой кнопкой по сцене | Один выстрел |
| «Урон 35» / «Урон 80» | Выбрать урон следующего выстрела |
| H / «Новая мишень» | Создать свежую мишень с 100 здоровья, сохранив положение игрока и выбранный урон |
| R | Сбросить весь стенд: положение, урон и состояние мишени |
| WASD или стрелки | Двигаться по осям мира |
| Q / E | Повернуть взгляд на 15 градусов |
| F | Посмотреть точно на мишень |
| «−» / «+» | Изменить дальность стрельбы |
| B | Показать три оси игрока |
| Space | Пауза: движение и выстрелы остановлены |
| Правая кнопка мыши / колесо | Вращать и приближать камеру |
| F2 / «Класс» | Открыть `target.h` в Блокноте |
| Esc | Закрыть стенд |

## Опыт: 100 → 65 → 0

1. Нажмите R. Панель показывает `getHealth() = 100`, `isAlive() = true`.
2. Нажмите J. Мишень получает 35 урона, остаётся 65 здоровья.
3. Выберите «Урон 80» и снова нажмите J. Получится 0 здоровья и `isAlive() = false`.
4. Во втором попадании запросили 80 урона, но фактически сняли 65 здоровья:
   ниже нуля оно не опускается. Панель отдельно показывает эту фактическую потерю.
5. Ещё один выстрел не меняет уничтоженную мишень. Нажмите H, чтобы создать новую.

## Что изменяет здоровье

Начните с `target.h`. В нём тот же класс, который мы разобрали в чате:

```cpp
Target target;
target.takeDamage(35);
target.takeDamage(80);

// target.getHealth() == 0
// target.isAlive() == false
```

Поле `health` закрыто через `private`. Внешний код не может написать
`target.health = -100`. Открытый метод `takeDamage()` игнорирует неположительный
урон и ограничивает здоровье нулём. `const` у методов чтения позволяет вызвать
их даже у неизменяемого объекта `const Target`.

У каждого экземпляра собственное здоровье: урон одному объекту не меняет другой.
Этот случай тоже проверяется в `checks.cpp`.

В `lesson.h` функция `shoot()` сначала проверяет `isAlive()` и сектор обзора из
урока 02. При попадании она вызывает `world.target.takeDamage(world.shotDamage)`.
`restoreTarget()` присваивает новый объект `Target{}` с начальным здоровьем;
прямого доступа к закрытому полю ей не требуется.

## Опыт: промах не наносит урон

1. Нажмите R, затем Q: мишень выйдет из сектора. Выстрелите — здоровье останется 100.
2. Нажмите F, чтобы направить взгляд на мишень.
3. Уменьшите дальность до 4 метров. Мишень в 5 метрах: выстрел снова не нанесёт урон.
4. Увеличьте дальность до 5 метров и выстрелите — попадание снова сработает.

## Сборка и проверки

Запустите `build.cmd` внутри этой папки. Используются Visual Studio C++ x86,
C++14 и Windows SDK. Скрипт соберёт приложение и выполнит все 44 проверки:
31 пример математики и движения из предыдущего урока и 13 проверок состояния
мишени, урона, отдельных экземпляров, восстановления и промахов.

Перед пересборкой закройте стенд. Промежуточные файлы по умолчанию создаются
во временной папке; свой путь можно указать через `BF2_LAB_BUILD_DIR`.

## Границы примера

Попадание в этом уроке определяется углом и дальностью до одной мишени.
Щелчок по сцене запускает выстрел по направлению взгляда игрока; точка курсора
не задаёт прицел. Геометрический луч, полёт пули, стены, столкновения и боезапас
пока не моделируются. Это учебный код для классов и состояния объекта.

Математические файлы OpenBF2 в `original/` сохранены без изменений. Их происхождение
и контрольные суммы указаны в `SOURCE.md`; копия лицензии GPL-3.0 включена в комплект.
