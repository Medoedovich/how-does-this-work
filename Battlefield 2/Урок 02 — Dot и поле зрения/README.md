# Урок 02 — Dot и поле зрения

[К списку уроков](../README.md) · [Предыдущий урок](<../Урок 01 — Движение и нормализация/README.md>)

Продолжаем работу с нормализованными векторами. Учимся вычислять скалярное
произведение, сравнивать его с порогом и проверять попадание флага в сектор обзора.
В C++ используем функции, `const`-ссылки, `bool`, условия и структуру результата `Sight`.

## Запуск

Откройте `VectorLab.exe` или `run.cmd` из этой папки. По умолчанию открыт режим
«Поле зрения». Первый режим сохранён для сравнения с предыдущим уроком.
Камера зрителя независима от направления взгляда игрока.

| Управление | Действие |
| --- | --- |
| WASD или стрелки | Движение по осям мира X и Z |
| Q / E | Повернуть взгляд на 15 градусов влево / вправо |
| F | Посмотреть точно на флаг |
| V | Включить/выключить поворот взгляда вслед движению |
| «−» / «+» | Изменить ширину сектора или дальность обзора |
| G | Автоматически идти к флагу |
| B | Показать три ортонормированные оси игрока |
| Space | Пауза для разбора значений |
| R | Сбросить координаты и настройки |
| 1 / 2 | Режим движения / режим поля зрения |
| Правая кнопка мыши + движение | Вращать камеру |
| Колесо мыши | Изменить масштаб |
| F2 | Открыть учебный `lesson.h` в Блокноте |
| Esc | Закрыть стенд |

## Опыт: dot и угол

1. Нажмите R. Игрок находится в `{1, 0, 2}`, флаг — в `{4, 0, 6}`.
   Направление взгляда `forward = {0, 0, 1}`, нормализованное направление к флагу
   `directionToFlag = {0.6, 0, 0.8}`.
2. Скалярное произведение равно `0 × 0.6 + 0 × 0 + 1 × 0.8 = 0.8`.
   Для нормализованных векторов это косинус угла между ними.
3. Сектор шириной 90 градусов допускает отклонение на 45 градусов в каждую сторону.
   Порог `cos(45°)` примерно равен 0.707. Угол до флага — примерно 36.87 градуса,
   поэтому флаг внутри сектора и подсвечен зелёным.
4. Нажмите Q один раз. Угол до флага станет примерно 51.87 градуса, `dot` — 0.617.
   Флаг всё ещё впереди: скалярное произведение положительное. При этом он уже
   за границей сектора в 45 градусов и подсвечен оранжевым.
5. Нажмите F. Направления совпадут: `dot = 1`, угол равен нулю.

## Опыт: одной проверки угла недостаточно

У флага в исходном примере расстояние до игрока равно 5 метрам.
После F уменьшите дальность до 4 метров: флаг больше не входит в сектор,
хотя направления полностью совпадают. Проверка требует подходящего угла
и подходящего расстояния одновременно.

Попробуйте A/D: можно идти боком, не поворачивая взгляд. Кнопка «Взгляд вслед
движению» включает автоматический поворот при движении. Вращение камеры мышью
меняет только то, откуда мы наблюдаем сцену.

## Что читать в коде

Начните с `lesson.h`:

- `dot()` — возвращает одно число по двум векторам.
- `Sight` — хранит направление, угол, порог и результаты проверок.
- `sightToFlag()` — нормализует направления и проверяет угол и дальность.
- `rotateLook()` — поворачивает взгляд вокруг вертикальной оси Y.
- `lookAtFlag()` — направляет взгляд точно на флаг.

`renderer.cpp` рисует сектор и показывает результаты вычислений. В `original/`
сохранены неизменённые математические файлы OpenBF2; происхождение и контрольные
суммы приведены в `SOURCE.md`.

## Сборка и проверки

Запустите `build.cmd` из этой папки. Он использует Visual Studio C++ x86, C++14
и Windows SDK, собирает приложение и запускает все 31 проверки. Проверяются
угловые и дистанционные границы, совпадение игрока с флагом, поворот взгляда
и примеры движения из предыдущего урока.

Перед пересборкой закройте окно этого стенда. Промежуточные файлы по умолчанию
помещаются во временную папку; путь можно задать через `BF2_LAB_BUILD_DIR`.

## Границы учебного примера

Проверка использует угол и дальность на плоскости XZ. Граница сектора и дальности
включена. При совпадении игрока и флага направление к флагу не определено —
это явно показано на панели. Стены и препятствия пока не проверяются.

Сцена показывает флаг во всех направлениях, чтобы было видно, как работает проверка.
Декоративные блоки не имеют столкновений. Это учебный стенд с математикой из OpenBF2;
полный движок, карты, сеть и игровые ресурсы Battlefield 2 здесь не подключены.
