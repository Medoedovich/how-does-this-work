# Урок 01 — Движение и нормализация

[К списку уроков](../README.md)

В этом уроке разбираем `struct`, поля и методы, функции, передачу по ссылке
и по значению. На игровом примере изучаем положение, скорость, расстояние,
нормализацию и ортонормированный базис. Это самостоятельная версия первого стенда.

Небольшая самостоятельная 3D-сцена для изучения C++ на примерах OpenBF2. Игрок, флаг, метровая сетка,
радиус захвата и стрелки показывают результат вычислений в C++ в реальном времени.

## Запуск

Откройте `VectorLab.exe` или `run.cmd`. Установка дополнительных библиотек не нужна.
Окно при необходимости можно развернуть. Сцена автоматически приостанавливает
обновление, когда активно другое приложение.

| Управление | Действие |
| --- | --- |
| WASD или стрелки | Движение по осям мира X и Z |
| G / «К флагу» | Автоматическое движение в точку флага; ручное движение его отменяет |
| Space | Пауза; сохраняет значения и стрелки для разбора |
| R / «Сброс» | Вернуть начальные координаты и настройки |
| N | Включить/выключить нормализацию ввода |
| C | Сравнить передачу вектора по ссылке и по значению |
| B | Показать три ортонормированные оси игрока |
| Правая кнопка мыши + движение | Вращать камеру вокруг площадки |
| Колесо мыши | Приближать/отдалять камеру |
| «Камера» | Вернуть исходное положение камеры |
| F2 / «Код» | Открыть учебный `lesson.h` в Блокноте |
| Esc | Закрыть окно |

Кнопки «−» и «+» изменяют скорость и радиус захвата.

## Первый опыт: наш пример 3–4–5

После сброса игрок находится в `{1, 0, 2}`, а флаг — в `{4, 0, 6}`.
До флага 5 метров, радиус равен 4 метрам: условие захвата ложно.
Нажмите G. Вектор к флагу нормализуется до `{0.6, 0, 0.8}`.
При скорости 2 м/с velocity равен `{1.2, 0, 1.6}`.
Нажмите Space, чтобы рассмотреть числа. Ещё одно нажатие продолжит движение.

Захват в этом стенде — только индикатор попадания в радиус.
Автоматическое движение продолжается до самой точки флага.

## Второй опыт: зачем ссылка

1. Нажмите R, удерживайте W+D. Скорость по диагонали будет около 2 м/с.
2. Нажмите C и снова двигайтесь по диагонали: будет около 2.83 м/с.
3. В режиме копии `normalizeCopy(Vec3 v)` нормализует только свою локальную копию.
   Вектор вызывающего кода остаётся `{1, 0, 1}` длиной примерно 1.414.
4. Умножение такого вектора на 2 даёт скорость примерно 2.83.

При автоматическом движении режим копии делает скорость зависящей от расстояния:
из исходной позиции будет 10 м/с вместо 2 м/с. Это намеренный учебный опыт.
Отсутствие нормализации даёт такой же эффект. У границы площадки фактическая
скорость ограничивается движением, которое удалось выполнить.

## Третий опыт: три оси

Нажмите B и немного подвигайтесь. Зелёная стрелка — forward, фиолетовая — up,
третья стрелка — third. Они строятся оригинальным методом
`Vec3::makeOrthonormalBasis()` из OpenBF2. Начало камеры также ориентируется этим
методом. Это позволяет экспериментировать с функцией, которую мы разбирали.

## Что читать и менять

Начните с **lesson.h**: в нём нормализация, ссылка/копия, расстояние, проверка радиуса
и `updatePlayer()`. Комментарии по-русски. Начальные координаты, скорость и радиус
заданы в `struct World`. Меняйте одно значение, собирайте и сравнивайте результат.

`renderer.cpp` отвечает за окно Windows, перспективную проекцию и отрисовку.
Для первых уроков его разбирать целиком не требуется.

В `original/` находятся неизменённые `Vec3.h`, `Vec3.cpp` и `BuildConfig.h` из
проекта OpenBF2. Происхождение и контрольные
суммы указаны в `SOURCE.md`. Стенд действительно компилирует этот C++-код,
а не изображает его выполнение в JavaScript.

## Сборка

Запустите `build.cmd`. Он найдёт установленный Visual Studio с инструментами C++,
выберет x86, соберёт приложение и запустит `VectorChecks.exe`.
В этой версии 16 проверок.
Используются C++14, Windows SDK и системные библиотеки Windows.
Промежуточные файлы создаются во временной папке; её можно явно выбрать переменной
окружения `BF2_LAB_BUILD_DIR`. Перед пересборкой закройте `VectorLab.exe`.

## Границы стенда

Из OpenBF2 используются математические типы и функции: `Vec3`, `getZero()`,
`distXZSqr()` и `makeOrthonormalBasis()`. Графика, ввод, движение, границы площадки
и индикатор захвата написаны для учебной сцены. Полный движок Battlefield 2,
его карты, модели, анимации, оружие, сеть и физика здесь не подключены.
Декоративные блоки не имеют столкновений. Y в этом уроке остаётся равным нулю.
Оригинальный проект и игровая установка не изменялись.

Исходники и копия лицензии GPL-3.0 включены в комплект. Стенд работает локально,
не подключается к сети и не требует установки дополнительного ПО для запуска.
