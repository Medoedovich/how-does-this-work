# Battlefield 2: изучаем C++ на практике

Небольшие уроки с работающей 3D-сценой и математическим кодом из OpenBF2.
Проходите их по номерам: каждый следующий урок развивает предыдущий.

| Урок | Что разбираем | С чего начать |
| --- | --- | --- |
| [01 — Движение и нормализация](<Урок 01 — Движение и нормализация/README.md>) | `struct`, поля, функции, ссылки и копии; координаты, расстояние, скорость, нормализация и три оси | Запустить `VectorLab.exe`, затем открыть `lesson.h` |
| [02 — Dot и поле зрения](<Урок 02 — Dot и поле зрения/README.md>) | Скалярное произведение, угол, порог, `bool`, условия и сектор обзора | Повернуть взгляд клавишами Q/E и сравнить `dot` с порогом |

## Как устроены папки

Каждая папка — самостоятельная версия стенда, соответствующая своему уроку.
В первом уроке сохранена версия до добавления поля зрения. Во втором — расширенная
версия, в которой первый режим также доступен для сравнения.

Внутри каждого урока находятся:

- `README.md` — объяснение, управление и опыты.
- `VectorLab.exe` и `run.cmd` — готовый стенд для Windows.
- `lesson.h` — основной учебный код с русскими комментариями.
- `renderer.cpp` — окно, камера и отрисовка.
- `checks.cpp` и `VectorChecks.exe` — проверки примеров этого урока.
- `build.cmd` — самостоятельная сборка урока через Visual Studio C++.
- `original/`, `SOURCE.md` и `LICENSE` — исходные файлы OpenBF2, их происхождение и лицензия.

## Запуск и сборка

Скачайте репозиторий и откройте нужную папку урока. Запустите `VectorLab.exe` или
`run.cmd` из этой папки. Корневой `run.cmd` открывает последний урок — сейчас это урок 02.

Для самостоятельной сборки нужны Visual Studio с инструментами C++ и Windows SDK.
Запустите `build.cmd` внутри урока, чтобы собрать только его, или корневой
`build.cmd`, чтобы по очереди собрать и проверить оба урока.

Проверки: урок 01 — 16; урок 02 — 31. Перед пересборкой закройте окно соответствующего стенда.

## Происхождение кода

OpenBF2 — независимая реконструкция движка Battlefield 2. В уроках используются
его математические типы и функции. Учебная графика, управление, движение и
проверки игрового состояния написаны отдельно. Полный движок и игровые ресурсы
Battlefield 2 для этих уроков не требуются.

Исходные файлы и лицензия включены в каждый урок. Готовые версии пройденных уроков
сохраняются в своих папках; следующие темы добавляются отдельными уроками.
