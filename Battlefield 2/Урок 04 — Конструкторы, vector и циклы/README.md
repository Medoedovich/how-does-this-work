# Урок 04 — Конструкторы, vector и циклы

[К списку уроков](../README.md) · [Предыдущий урок](<../Урок 03 — Классы, здоровье и урон/README.md>)

Создаём несколько независимых мишеней, храним их в `std::vector` и обрабатываем
циклом `for`. Сравниваем настоящее изменение объектов через `Target&` с прогнозом,
который вычисляется на копиях `Target`.

## Запуск и управление

Откройте `VectorLab.exe` или `run.cmd` из этой папки.
Начальное здоровье мишеней: 100, 150, 200 и 75. По умолчанию выбран урон 35.

| Управление | Действие |
| --- | --- |
| 1–4 / кнопки с номерами | Выбрать мишень |
| P / «Предпросмотр на копиях» | Показать, сколько здоровья останется после группового урона |
| X / «Нанести урон всем» | Применить выбранный урон к настоящим объектам |
| «Урон 35» / «Урон 80» | Выбрать величину урона |
| J / левая кнопка по сцене | Выстрелить по выбранной мишени с учётом сектора и дальности |
| H | Создать заново все четыре мишени; выбранный урон и положение игрока сохраняются |
| R | Сбросить весь стенд |
| WASD или стрелки | Двигаться |
| Q / E | Повернуть взгляд |
| F | Посмотреть на выбранную мишень |
| «−» / «+» | Изменить дальность одиночного выстрела |
| Space | Приостановить движение и нанесение урона |

## Опыт 1: конструктор и отдельные объекты

В `target.h` конструктор получает начальное здоровье:

```cpp
Target(int startHealth = 100)
    : health(startHealth)
    , maximumHealth(startHealth)
{
    if (health < 0)
    {
        health = 0;
        maximumHealth = 0;
    }
}
```

Двоеточие начинает список инициализации полей. Текущее и максимальное здоровье
задаются при создании объекта. Значение по умолчанию `= 100` позволяет также
создать `Target target;` без аргумента. Отрицательное начальное значение обнуляется.

Мишени создаются независимо: `Target{100}`, `Target{150}`, `Target{200}`, `Target{75}`.
Кнопки 1–4 выбирают, какой объект показывать на панели. Одиночный выстрел J
изменяет только выбранную мишень.

## Опыт 2: std::vector и индексы

В `World` находится контейнер:

```cpp
std::vector<Target> targets{
    Target{100}, Target{150}, Target{200}, Target{75}
};
```

`targets.size()` равен 4. Индексы начинаются с нуля: мишень №1 — это `targets[0]`,
мишень №4 — `targets[3]`. При переключении кнопок индекс виден над полоской здоровья.
Состав списка в этом стенде фиксирован: четыре мишени.

## Опыт 3: настоящий урон через ссылку

Нажмите R, затем X. Здоровье изменится:

```text
Было:   100, 150, 200, 75
Стало:   65, 115, 165, 40
```

Это делает `applyDamageToAll()` в `lesson.h`:

```cpp
for (Target& target : world.targets)
{
    target.takeDamage(world.shotDamage);
}
```

На каждом проходе `target` ссылается на очередной объект внутри контейнера.
Изменения сохраняются в игровом мире.

## Опыт 4: полезная копия для прогноза

1. Нажмите R и P. Над каждой мишенью появится фиолетовый прогноз: 65, 115, 165, 40.
2. Настоящее здоровье останется 100, 150, 200, 75. Переключайте мишени 1–4:
   основная полоска показывает реальное здоровье, тонкая фиолетовая — прогноз.
3. Нажмите X. Настоящее здоровье станет таким, каким был прогноз.
4. Выберите урон 80 и снова нажмите P: новый прогноз — 0, 35, 85, 0.
5. Нажмите X: этот результат применится ко всему списку. Здоровье каждого объекта
   независимо ограничивается нулём.

Прогноз вычисляет `predictHealth()`:

```cpp
std::vector<int> result;

for (Target prediction : world.targets)
{
    prediction.takeDamage(world.shotDamage);
    result.push_back(prediction.getHealth());
}
```

`prediction` создаётся как копия очередной мишени. Копия получает урон, а её
результат записывается в отдельный список чисел. Настоящий объект сохраняется.
Функция возвращает список прогнозируемого здоровья по значению.

| Переменная цикла | Как работаем с объектом |
| --- | --- |
| `Target& target` | Изменяем исходный объект |
| `const Target& target` | Читаем исходный объект без копирования |
| `Target target` | Работаем с отдельной копией |

В `renderer.cpp` исходные мишени читаются через `const Target&`, чтобы рисовать
их состояние. Функции прогноза и нанесения урона используют один и тот же выбранный
урон. После настоящего действия предпросмотр выключается; P показывает новый прогноз.

## Сборка и проверки

Запустите `build.cmd` внутри урока. Используются Visual Studio C++ x86, C++14
и Windows SDK. Скрипт собирает приложение и выполняет 56 проверок: примеры
прошлых уроков, конструкторы, сохранность объектов при прогнозе, совпадение
прогноза с настоящим уроном, восстановление списка и выбор отдельной мишени.

Перед пересборкой закройте стенд. Промежуточные файлы помещаются во временную
папку; свой путь можно указать через `BF2_LAB_BUILD_DIR`.

## Границы примера

«Нанести урон всем» демонстрирует обработку контейнера и действует на весь список,
независимо от угла и расстояния. Это правило учебного опыта; физика взрыва не моделируется.
Одиночный выстрел J по-прежнему проверяет сектор и дальность выбранной мишени.
Курсор не задаёт прицел. Стены, полёт пули и столкновения пока не проверяются.

Математические файлы OpenBF2 в `original/` сохранены без изменений. Происхождение
и контрольные суммы указаны в `SOURCE.md`; копия лицензии GPL-3.0 включена в комплект.
